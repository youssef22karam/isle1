# isle1 — Tidewater Islands

A single-file WebGPU archipelago: tidewater's sea, boat, shoreline waves, sky, sun and clouds (with its day/night cycle and weather/sea-state system) combined with island29's complete island generator — archetypes, hydrology with rivers, lakes and wetlands, erosion and geology — streamed as an endless world of islands behind a floating origin. Controls are island29's scheme (menu button, analog stick, hold-to-run, Look/Walk/Boat) plus environment controls for time of day, cycle speed, sun azimuth, cloud cover and the weather presets/sliders.

## Build

```sh
npm install
npm run build   # writes the self-contained game to dist/index.html
npm run dev     # local dev server
```

`npm install` pulls Vite from the registry; the `three` dependency is a tiny local stub (`vendor/three-stub/`, wired via a `file:` dependency) that only satisfies two class names island29's hydrology module imports but the generator never calls. `package-lock.json` is not committed; it is regenerated by install.

## Split files

Every committed file is at most 30,000 bytes. Thirteen source files exceed that, so they are committed as byte parts in `<name>.parts/` directories (27 parts in total) and the whole files are gitignored. `tools/reassemble.mjs` joins the parts back into the wholes byte-for-byte; it runs automatically through the `predev`/`prebuild`/`prepreview` npm hooks and refuses to proceed if any part exceeds 30,000 bytes. After editing a whole file, run `node tools/split.mjs` to regenerate its parts. The largest committed file is 29,606 bytes.

## Layout

- `src/` — the game: tidewater's engine/ocean/world code, island29's generator under `src/islands/gen/`, and the hybrid's glue under `src/islands/`
- `test/` — node test/check suites (note: `test/generator-fidelity.test.mjs` needs its 2 MB reference fixture `test/fixtures/home-kn-504.bin`, which is not committed because of its size)
- `tools/` — `reassemble.mjs` / `split.mjs` packaging tools
- `REPORT.md` — the full build report (itself split into `REPORT.parts/`)
- `THIRD-PARTY-LICENSE.txt` — tidewater's MIT license

169 files in total.
